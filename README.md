# 💸 Expense Tracker

A simple and interactive **Expense Tracker** built with HTML, CSS, and JavaScript. Track your income and expenses, manage transactions, and visualize your spending habits through interactive charts — all directly in your browser.

---

## ✨ Features

- **📊 Dashboard Overview** — View your total expenses, total income, and remaining balance.
- **➕ Add Transactions** — Add transactions with a description, category, amount, status, and date.
- **📁 Expense Categories** — Organize expenses into different categories:
  - Food & Groceries
  - Housing & Bills
  - Shopping & Lifestyle
  - Health & Education
  - Entertainment & Recreation
  - Miscellaneous
- **📋 Transaction History** — View your previously added transactions in a table.
- **🗑️ Delete Transactions** — Remove transactions you no longer need.
- **📈 Interactive Charts** — Visualize your financial activity using Chart.js:
  - Line chart for spending activity.
  - Doughnut chart for category-wise expenses.
- **💾 Local Storage** — Your transactions are saved in the browser using `localStorage`, so they remain available after refreshing the page.
- **📱 Responsive Layout** — The interface adapts to different screen sizes.

## 📖 How to Use

1. Open the Expense Tracker in your browser.
2. Click the **Add Transaction** button.
3. Enter the transaction description.
4. Select a category.
5. Enter the amount and choose a status.
6. Select the transaction date.
7. Click **Add Expenses** to save the transaction.
8. View your updated dashboard, transaction history, and charts.
9. Use the delete option to remove a transaction.

---

## 💾 Data Storage

This project uses the browser's built-in `localStorage` API to save transaction information.

- No database or backend server is required.
- Transaction data is stored locally in your browser.
- Data remains available when you refresh or reopen the page in the same browser.
- Clearing the browser's site data may remove saved transactions.
